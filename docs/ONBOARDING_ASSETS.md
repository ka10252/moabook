# 온보딩 화면 사진 (public/onboarding/*.webp)

'보는 방식' 단계에 들어가는 **실제 앱 화면 조각** 3장이다.

| 파일 | 담은 것 |
|---|---|
| `view-spine.webp` | 서가 한 칸 — 책등이 꽂힌 한 줄 |
| `view-cover.webp`  | 표지 뷰 한 줄 — 표지 3권(꽤 낙천적인 아이·나미야 잡화점의 기적·야간비행) |
| `view-map.webp`    | 지도 뷰 — 역마다 책이 몇 권 있는지 |

## 왜 그림이 아니라 사진인가

처음엔 도형으로 흉내낸 그림을 넣었다. 책등은 그럭저럭 통했지만 **표지 뷰와 지도 뷰가
실제로 어떻게 보이는지는 전혀 전달되지 않았다.** 온보딩의 목적은 "이런 게 있다"가 아니라
"눌러보면 이렇게 된다"를 미리 보여주는 것이라, 실제 화면을 잘라 넣는다.

## 다시 뽑는 방법

디자인이 바뀌면 사진도 같이 갱신해야 한다 (안 하면 앱과 어긋난 채로 남는다).

1. `npm run dev` 로 띄우고 책이 여러 권 있는 계정으로 로그인
2. Playwright 로 `deviceScaleFactor: 2`, 뷰포트 420×900 에서 각 뷰를 열고
   **가로로 길게**(약 338×172 CSS px) 잘라 PNG 로 저장
3. WebP 로 줄인다 — **640×118**, quality 84. 세 장 합쳐 **22KB**

⚠️ **비율(640×118)은 임의로 정한 게 아니다.** 사진 3장을 세로로 쌓고도 작은 폰에서
스크롤이 안 생기는 한계선이다. 실측으로 좁혀 넣은 값이라 조금만 높여도 넘친다:

| 화면 | 카드가 쓸 수 있는 높이 | 640×150 | 640×128 | **640×118** |
|---|---|---|---|---|
| 360×640 (안드로이드) | 265px | 넘침 | 10px 넘침 | ✅ |
| 375×667 (iPhone SE 3세대) | 283px | 29px 넘침 | ✅ | ✅ |
| 393×852 (iPhone 14 Pro) | 468px | ✅ | ✅ | ✅ |

320×568(2016년 iPhone SE 1세대)만 40px 남짓 넘친다. 거기까지 맞추려면 사진이
25px 높이가 되어 아무것도 안 보이므로 포기했다.
   (PNG 그대로면 700KB가 넘어 온보딩 첫 화면이 느려진다)

```python
from PIL import Image
im = Image.open('shot.png').convert('RGB')
im = im.resize((640, round(im.height * 640 / im.width)), Image.LANCZOS)
im.save('public/onboarding/view-cover.webp', 'WEBP', quality=80, method=6)
```

## 사진에 담지 말 것

- **다른 유저의 닉네임·프로필 사진.** 책등 뷰의 리본에는 빌려준/빌린 사람 이름칩이 붙는다.
  이름칩이 없는 선반 줄을 골라 잘랐다.
- 하단 탭바·플로팅 버튼. 화면 중간으로 스크롤해서 잘라야 안 걸린다.

## 카드 높이

'보는 방식'은 사진 3장이라 온보딩 카드 중 가장 길다(약 740px). 그래서 카드는
**내용만 스크롤하고 진행 버튼은 고정**한다 — 예전엔 카드 전체가 스크롤돼서
iPhone SE(667px)에서 '다음' 버튼이 아래로 밀려 찾아야 했다.
사진을 더 넣으면 `npm run smoke` 로는 안 잡히니, 작은 뷰포트에서 버튼이 보이는지 직접 볼 것.


## 원하는 책으로 표지 줄을 만들려면

표지 뷰는 서가 순서대로 3권씩 끊어 그리므로, 보여주고 싶은 3권이 나란히 오는 일은 드물다.
DOM 을 옮겨 붙여봤지만 React 의 등장 애니메이션(opacity/transform)이 복제본에서 다시 돌지 않아
**세 번째 칸이 투명하게 비었다.** 억지로 `opacity:1` 을 먹이면 이번엔 hover 용 제목 오버레이가 드러났다.

→ 결론: **표지를 한 장씩 따로 찍어 크림 바탕에 나란히 붙인다.**
   실제 앱이 그린 픽셀을 그대로 쓰되 배치만 우리가 한다.

```
1. 표지 뷰에서 모든 img 를 loading='eager' 로 바꾸고 끝까지 스크롤해 전부 로드
2. '대여중·빌린책' 배지는 display:none (이 사진의 주제가 아니다)
3. 책마다 scrollIntoView → img 의 getBoundingClientRect() 로 clip 스크린샷
4. PIL 로 크림색(246,238,222) 바탕에 같은 간격으로 붙이고 640×216 으로 저장
```
