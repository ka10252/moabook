## 1. 개발자 계정 — 가장 먼저, 병렬로

### 1-1. Google Play를 먼저 시작할 것 ⚠️

직관과 반대지만 **Play가 Apple보다 오래 걸린다.**
개인(Personal) 개발자 계정은 프로덕션 출시 전 **클로즈드 테스트를 일정 인원이 연속 며칠간** 유지해야 한다.
(도입 이후 인원·기간 요건이 여러 번 바뀌었다 — 현재값은 Play Console 안내 확인. 대략 **12~20명 / 14일** 수준)

→ 테스터 확보에 시간이 걸리므로 **오늘 당장 계정을 만들고 테스터 모집을 시작**해야 한다.
→ NUS 한인회·교회 시드 커뮤니티가 그대로 테스터 풀이 된다.

- [ ] Google Play Console 계정 생성 (**$25, 1회**)
- [ ] 신원 확인 (신분증 + 주소 확인, 며칠 소요)
- [ ] 계정 유형 결정: Personal vs Organization
- [ ] 클로즈드 테스트 트랙 생성 → 테스터 이메일 목록 확보
- [ ] 테스트 시작일 기록 (요건 충족 시점 역산)

## 5. 국가/지역 결정 ⚠️ 지금 막혀 있는 지점

한국 국적 + 싱가포르 거주라 **어느 나라로 등록할지 먼저 정해야** 한다.

| | 한국 등록 | 싱가포르 등록 |
|---|---|---|
| 신분증 | 여권·주민등록증 ✅ | Student Pass로 가능한지 불확실 ⚠️ |
| 결제수단 | 한국 카드 ✅ | 싱가포르 카드 필요 |
| 주소 | 한국 주소 ✅ | 싱가포르 주소 |
| 난이도 | **낮음** | 높음 |

- [ ] Apple Account 국가/지역 확인 (`appleid.apple.com` → 로그인 및 보안 / 결제)
- [ ] 신분증·결제수단·주소의 국가를 **하나로 통일**
- [ ] 결정: **한국 권장** (서류가 이미 다 있음)

> **배포 국가는 별개다.** 한국 계정으로 등록해도 앱은 싱가포르를 포함한 원하는 국가에 배포할 수 있다.
> 개발자 계정 국가는 세금·결제 처리 기준일 뿐, 타깃 시장과 무관하다.

- [ ] `@capacitor/core`, `@capacitor/cli` 설치 후 `npx cap init`

  - 텔레그램을 1순위 채널로 쓰기로 했으므로 **네이티브 푸시를 v1에서 뺄 수 있는지** 먼저 검토
- [ ] 하드웨어 뒤로가기(Android) 처리 — 기존 뒤로가기 이탈 방지 로직과 충돌 확인
- [ ] Safe area / 노치 대응
- [ ] 오프라인·네트워크 오류 화면
- [ ] Android `targetSdkVersion` — Play는 매년 최신 API 레벨을 강제한다
- [ ] iOS 최소 지원 버전 결정
- [ ] 앱 서명: Play App Signing 등록 / iOS 인증서·프로비저닝 프로파일
- [ ] 버전·빌드 번호 체계 (`1.0.0` / 빌드 정수 증가)
- [ ] 크래시 리포팅 (Sentry 등) — PRD의 미완 항목

> **Phaser(가상공간)가 네이티브 WebView에서 정상 동작하는지 실기기 확인이 필요하다.** 데스크톱 브라우저와 다르게 동작할 수 있는 가장 큰 후보다.

## 🔴 배포 전 반드시 되돌릴 것 (개발용으로 켜둔 설정)

| 파일 | 설정 | 지금 | 배포 시 |
|---|---|---|---|
| `capacitor.config.ts` | `ios.webContentsDebuggingEnabled` | `true` | **`false`** 또는 Debug 전용 |
| `capacitor.config.ts` | `loggingBehavior` | `'debug'` | 그대로 둬도 된다(Debug 빌드에서만 로그) |

### 왜 켜뒀나
Capacitor 8은 **SPM xcframework**로 들어와서, 자동 판단에 쓰이는 `#if DEBUG`가
우리 앱이 아니라 프레임워크의 빌드 설정을 본다 → 항상 거짓이 되어
**Safari 개발자용 메뉴에 Simulator가 아예 안 뜬다.** 그래서 명시적으로 켰다.

### 왜 위험한가
켜둔 채로 스토어에 올리면 **배포본의 웹뷰를 누구나 Safari로 열어볼 수 있다.**
로컬스토리지의 세션 토큰까지 보인다.

### 더 나은 방법(시간 있을 때)
`Info.plist`에 `CAPACITOR_DEBUG = $(CAPACITOR_DEBUG)` 를 넣고, Xcode 빌드 설정에서
Debug=`true` / Release=`false` 로 두면 설정 파일을 손대지 않아도 자동으로 갈린다.
